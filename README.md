# PetraERP

نظام ERP محاسبي عربي/إنجليزي بـ C# و.NET 10، وAPI مركزي لأندرويد والويب وWPF،
وقاعدة SQL Server مستقلة لكل تركيب عميل (قاعدة لكل شركة/سنة مالية).

**الحالة: ليس ERP تجارياً مكتمل الوحدات، وقرار الإصدار الحالي NO-GO.** التفاصيل والأدلة
المؤرَّخة في [`docs/closure/`](docs/closure/): ابدأ من
[الحالة الحالية](docs/closure/00_CURRENT_STATE.md) و[قرار الإصدار](docs/closure/RELEASE_GO_NO_GO.md)،
ثم [قائمة البوابات](docs/PetraERP_EXECUTION_GATES_CHECKLIST.csv). ما بُني فعلاً وما بقي مكتوب هناك
بأرقام مقيسة، لا هنا.

## الموجود فعلياً (مصدر، يُتحقق منه بالتشغيل)

- **النواة المحاسبية:** دليل حسابات هرمي، مراكز تكلفة، سنوات وفترات، قيود من المسودة إلى الترحيل والعكس المرتبط،
  دفتر أستاذ بترقيم بالمؤشر، ميزان مراجعة، تسوية بنك، إعادة تقييم عملات، ترحيل جماعي، أرصدة افتتاحية.
- **المستندات:** مبيعات ومشتريات وسندات قبض/دفع وتسوية فواتير ومخزون (تحويل، جرد، صرف داخلي) بأنماط مستندات وترقيم ذري.
- **التكامل:** API v1 موثّق بـOpenAPI (نحو 300 عملية) وعميل C# مُولَّد؛ ثبات الترحيل بمفاتيح تكرار دائمة.
- **Desktop (WPF/MVVM):** يتكلم مع الخادم عبر العميل المُولَّد فقط ولا يصل إلى SQL.
- **منصة الوحدات:** حزم موقّعة، بوابات ترحيل مالي/مخزني، مدير وحدات في الخادم (واجهة مدير الوحدات في Desktop لم تُبنَ بعد).

الأرقام الدقيقة (جداول، ترحيلات، صلاحيات، عمليات) تتغير؛ استخرجها من المصدر عند الحاجة:
`src/PetraERP.Infrastructure/Persistence/AccountingMigrations`، `PermissionCatalog.cs`،
و[`docs/closure/API_ROUTE_MAPPING.csv`](docs/closure/API_ROUTE_MAPPING.csv).

## البناء والتحقق

```powershell
& tools/Verify.ps1
```

اختبارات SQL الصريحة تحتاج `PETRAERP_SQL_TEST_SERVER` (مثل `.\SQLEXPRESS`) و`PETRAERP_SQL_TEST_TRUST_CERTIFICATE=1`
ثم `--explicit on` على ملف الاختبار التنفيذي. ملاحظات التشغيل والنتائج في
[`TEST_EXECUTION_EVIDENCE.md`](docs/closure/TEST_EXECUTION_EVIDENCE.md).

التشغيل يحتاج `desktopsettings.json` بعنوان HTTPS صالح، وخادم API مهيأ وقاعدة مهاجرة ومديراً منشأً عبر CLI؛
لا بيانات دخول أو بيانات مالية افتراضية.
