# PetraERP

نظام ERP محاسبي عربي/إنجليزي بـ C# و.NET 10، وAPI مركزي لأندرويد والويب وWPF،
وقاعدة SQL Server مستقلة لكل تركيب عميل.

**تم إصلاح وإكمال التنفيذ المتوقف لواجهات System/Security ودفتر الأستاذ العام، والتحقق
آلياً من مساراتها. المرحلة الخامسة ما زالت جارية لحين قبول التطبيق المثبت وDPI الفعلي
واختبار SQL Server 2025. هذا ليس ERP تجارياً مكتمل الوحدات.**

ابدأ من [التسليم المستمر](docs/ai/HANDOFF.md)، [المنفّذ والمتبقي](PROJECT_PROGRESS_AR.md)،
[مصفوفة الميزات](docs/FEATURE_MATRIX.md)، [حالة المرحلة الخامسة](docs/phase-5/STATUS.md)،
و[تفاصيل الواجهات والأدلة](docs/ux/WORKSTATION_DELIVERY.md).

آخر متابعة: [تدقيق دورة حياة الحساب](docs/implementation/PHASE1_SLICE4.md)، مع تبويب تدقيق
فعلي وقيم قبل/بعد وحذف آمن مختبر عبر الواجهة والخادم. المصدر الحالي 28 جدولًا و11 ترحيلًا
و18 صلاحية و72 عملية API؛ التحقق الشامل ناجح: 418 اختبار C# و34 اختبار أدوات، بلا فشل
أو تخطٍّ، والبناء بلا تحذيرات أو أخطاء، وتطابق العميل ناجح وفحص الحزم بلا ثغرات معلنة.

## الموجود فعلياً

- واجهة موحدة: دخول وجلسة محمية، شركة/فرع/عملة/فترة مالية، مستخدمون وأدوار وتدقيق أمني.
- دليل حسابات هرمي، مراكز تكلفة، سنوات وفترات، قيود كاملة من المسودة إلى الترحيل
  والعكس المرتبط، ويومية عامة وكشف حساب وميزان مراجعة عبر API حقيقي.
- بحث سريع بلوحة المفاتيح، Ctrl+K، حديث ومفضلة أوامر وتقارير وتخطيط جداول محفوظ على الخادم.
- حالات وصلاحيات فعلية، تزامن وتأكيدات وأخطاء مترجمة؛ مجاميع وأرصدة محفوظة من الخادم.
- عربية RTL وإنجليزية LTR، Light/Dark/System، دون مكونات UI مدفوعة مضافة.
- تخطيط يستجيب لضيق الشاشة بتبويبات وتمرير محدود، مع اختبارات للمقاسات المنطقية ولوحة المفاتيح؛
  [قبول Windows المثبت](docs/ux/DPI_KEYBOARD_ACCEPTANCE.md) ما زال مطلوباً.
- 7 مشاريع إنتاجية و5 اختبارات؛ Desktop لا يصل إلى SQL مباشرة.
- المصدر الحالي: 28 جدولًا، 11 ترحيلًا، 18 صلاحية، 72 عملية API v1 وعميل C# مولد.

متابعة 2026-10-18: إصلاح تعارض تعديل بطاقة الحساب، وربط حساب سطر القيد بدفتر الأستاذ،
ومراجعة عمل الحفظ عند الإغلاق والتنقل والحذف الآمن واستعادة التبويبات. التحقق الشامل ناجح:
412 اختبار C# و34 اختبار أدوات، بلا فشل أو تخطٍّ، والبناء بلا تحذيرات أو أخطاء، وتطابق
الـAPI والعميل ناجح؛ فحص الحزم للمشاريع الاثني عشر بلا ثغرات معلنة.
راجع [ملفات التغيير والتحقق والمتبقي](docs/implementation/PHASE1_SLICE3.md).

لا شاشات فواتير أو مخزون أو أوامر طباعة/تصدير وهمية. لا سجل أسعار صرف تاريخي أو
إقفال نهاية سنة أو قوائم مالية كاملة. الأطراف والوحدات التالية لم تبدأ.

## البناء والتحقق

```powershell
& tools/Verify.ps1
```

للتحقق مع SQL المعزول، اتبع إعدادات HANDOFF ثم `tools/Verify.ps1 -IncludeSqlTests`.
تحقق 2026-10-17 التاريخي: **34 Python و391 C# ناجحة، صفر فشل/تخطٍّ، Release بلا تحذيرات أو أخطاء**؛
منها 72 SQL على الإصدار 16. OpenAPI والعميل متطابقان، وفحص حزم 12 مشروعاً دون ثغرات معلنة.
صور الواجهات وفحص الربط الآلي موجودة محلياً في `.artifacts/ux-recovery/visual/INDEX.md`.
الصور ليست قبولاً لشاشة فعلية عالية التكبير أو اختبار أداء LAN.

التشغيل يحتاج `desktopsettings.json` بعنوان HTTPS صالح، وخادم API مهيأ وقاعدة مهاجرة
ومديراً منشأً عبر CLI؛ لا بيانات دخول أو بيانات مالية افتراضية. المصدر المبني محلياً:
`src/PetraERP.Desktop/bin/Release/net10.0-windows/PetraERP.Desktop.exe`.
راجع [المصادقة](docs/security/AUTHENTICATION.md) و[خارطة الطريق](docs/ROADMAP.md).

legacy-data للقراءة فقط ومستثنى من Git والتوزيع. Git على main بلا commit؛ لم تُنشأ
حزمة توزيع جديدة، وPetraERP.zip قديم. المواصفات المقدمة مبتورة بعد PHASE 13 / Re؛
لا متطلبات مفقودة مخترعة. القبول المثبت وSQL 2025 والأداء والتثبيت الموقّع ما زالت متبقية.
