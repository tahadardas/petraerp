# FRONTEND_RELEASE_CHECKLIST — قائمة تدقيق إطلاق واجهة PetraERP Next

**التاريخ:** 19 نوفمبر 2026  
**المرجع:** `srs/PetraERP_Next_React_TypeScript_SRS_MASTER_v2_6_AR.md`  
**البيئة:** Windows Desktop (React 19 + TypeScript + Vite + Tauri 2)

---

## 1. السلامة المحاسبية وحظر الحسابات المحلية (Financial Integrity)

- [x] **الأرقام العشرية:** جميع المبالغ تُمرر كنصوص عشرية دقيقة (decimal string)، ويحظر استخدام الأرقام العائمة الثنائية (JavaScript `number` / `float`) في العمليات الحسابية.
- [x] **سلطة الخادم المطلقة:** الواجهة لا تقوم بأي ترقيم مستندات محلي، أو حساب أرصدة أستاذ، أو توليد قيود ترحيل؛ جميعها تأتي من الخادم عبر OpenAPI.
- [x] **عدم قابلية تعديل المستندات المرحلة:** عند ترحيل المستند، يتم قفل جميع حقول الإدخال ويتحول الزر إلى «عكس القيد / المستند» فقط مع تتبع مرجع الإلغاء.
- [x] **الطرف الموحد:** يتم التعامل مع العميل والمورد بنفس الحساب الموحد وفق قرار المالك (الخيار A)، وعرض كشف الحساب الموحد بشفافية تامة.

---

## 2. محرك الجداول وتجربة المحاسب (Accountant-First Input & Grid Engine)

- [x] **التمرير الافتراضي (Virtualization):** الجداول التي تتجاوز 200 سطر وحتى 10,000 سطر تستخدم التمرير الافتراضي مع ثبات عدد عناصر الـ DOM لتجنب بطء الواجهة أو تجمدها.
- [x] **الأسطر الجاهزة للإدخال:** كل جدول مستند مالي (قيود، فواتير، سندات) يفتح فوراً بـ 50 سطراً فارغاً جاهزاً للكتابة المباشرة دون الحاجة للضغط على "إضافة سطر".
- [x] **التنقل بلوحة المفاتيح:**
  - `Enter` و `Tab` ينتقلان للخلية التالية حسب اتجاه القراءة (RTL).
  - السهم لأعلى ولأسفل يتنقل بين الأسطر.
  - `F2` يفتح البحث في الخلية المحددة.
  - `F3` يفتح دليل المواد السريع.
  - `F9` أو `Ctrl+S` يحفظ المستند.
  - `Esc` يغلق النوافذ المنبثقة والقوائم السياقية.
- [x] **الحافظة المتوافقة مع Excel:** النسخ من الجدول ينسخ بيانات TSV حقيقية، واللصق في الجدول يدعم لصق مئات الأسطر مع تخطي الأعمدة للقراءة فقط.

---

## 3. بيئة سطح المكتب وشبكة LAN المحلية (Desktop & LAN Environment)

- [x] **عزل الشركات والفروع:** ترويسة `X-Petra-Workspace` تُرسل في كل طلب HTTP لعزل بيانات الشركات والسنوات المالية.
- [x] **شريط الحالة المكتبي (PetraStatusBar):** يعرض اسم الشركة الحالية، السنة، الفرع، المستخدم، وحالة الاتصال بالمللي ثانية (ms).
- [x] **لوحة الأوامر السريعة (PetraCommandPalette):** اختصار `Ctrl+K` يفتح بحثاً سريعاً عن الشاشات والوظائف للوصول الفوري بدون فأرة.
- [x] **معالجة انقطاع الشبكة:** إشعار toast فوري عند تعذر الوصول لخادم الشبكة المحلية مع المحافظة على البيانات غير المحفوظة في الشاشة الحالية.

## 4. إمكانية الوصول ودعم اللغة العربية (RTL & A11y)

- [x] **الاتجاه الافتراضي:** واجهة عربية RTL أصيلة مع دعم التبديل إلى LTR في الإعدادات.
- [x] **الهوية البصرية:** اعتماد ألوان Petra Calm Enterprise (#17334C, #087E87, #EEF3F8, #253447) بدرجات تباين تلبي معايير WCAG AA.
- [x] **الخطوط:** استخدام IBM Plex Sans Arabic كخط رسمي حر ومريح للعين مع بدائل النظام Segoe UI / Noto Sans.
- [x] **مؤشرات التركيز:** إطار تحديد الخلية والمكون النشط بلون بارز (#087E87) لتسهيل العمل بدون فأرة.
