# AMN-VPAT-GATE-005 — شاشة إدارة أنماط السندات (التقرير) · يتوقف للمراجعة البصرية

**الأساس:** `879bbb3`. **ملاحظة تقنية:** نص البوابة يذكر React/Tauri، لكن واجهة هذا المشروع هي WPF (قيد المشروع في AGENTS.md: WPF مع MVVM، ولا شاشات مكررة). نفّذتُ التوسعة داخل **بطاقة النمط الحالية** نفسها لا شاشة جديدة.

## ما نُفِّذ
| الملف | التغيير |
|---|---|
| `Patterns/PatternCardViewModel.Voucher.cs` (جديد) | إعدادات السند: عناوين الأعمدة (مدين/دائن أو من/إلى)، وضع الترحيل (حسب الشركة / يدوي فقط)، تاريخ القطع، الحسابات ومراكز الكلفة المسموحة، والمعاينة الفعلية |
| `Patterns/PatternCardView.xaml` | بطاقة «إعدادات السند» (تظهر لعمليات السند فقط) بعد بطاقة الاعتمادات في تبويب «الاعتمادات والترقيم» |
| `Patterns/PatternCardViewModel.cs` | ربط التحميل والحفظ: `SchemaVersion = 2` و`Voucher` ضمن الإعدادات المرسلة؛ يحفظ كل ما عداها دون فقد |
| `IPatternsClient` + `PatternsClient` | `GetEffectivePatternAsync` (قراءة النمط الفعّال من الخادم) |

- **المعاينة الفعلية:** زر «قراءة من الخادم» يستدعي `GET patterns/{id}/effective` ويعرض ما يشغّله الخادم للنسخة المنشورة (نوع التشغيل، العناوين، الترحيل، القطع، الاعتماد وحده، الحسابات المسموحة، قواعد الحقول). ليست تخميناً محلياً.
- **لا خيارات شكلية:** الخيارات غير المفعَّلة بعد (قيد لكل قلم، ترحيل لحظة الاعتماد، قبض/دفع متعدد الطرق) **غير معروضة**، ولا تُرسَل (`PerLineJournal=false`, `AutoPost=false`, `FormKind=GenericVoucher`).
- **الحفظ:** تعديل الإعدادات يُحفظ كمسودة نسخة جديدة عبر زر «مسودة إصدار جديدة» (المسار القائم لكل إعدادات الإعدادات)، ثم تُنشر النسخة كالمعتاد.

## إصلاح اكتُشف أثناء العمل
بطاقة النمط كانت تعرض حقول المسودة بقيمها الافتراضية في وضع العرض عند الفتح (لا تُحمَّل إلا عند بدء التعديل). صار الفتح يحمّلها من السجل المقروء (`LoadAsync`). لم أغيّر سلوك إعادة التحميل بعد إنشاء نسخة (تبقى القيم المكتوبة كما كانت).
