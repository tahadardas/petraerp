# GO / NO-GO

**القرار: NO-GO** (حتى إغلاق P0 وكل الفروقات المالية = صفر **مع** كامل الاختبارات الإلزامية).

| شرط الإصدار | الحالة |
|---|---|
| Build Release | PASS |
| P0: كاش Workspace | مغلق (اختبارات وحدة) — لم يُثبَت عبر واجهة WPF كاملة |
| P0: Idempotency/Retry | **مغلق عمليًا**: العميل يحلل المفتاح ويعيد بنفس المفتاح بعد 503 أو ضياع الرد، والخادم يعيد الوحدة كاملة عند 1205 ويعيد الإيصال المخزن. لا endpoint حالة مستقل |
| P0: Deadlock (مبيعات) | **مُعالَج جذريًا**: تعارض `ActorReferences` + تسريب عزل SERIALIZABLE؛ 0 deadlock حتى 50 مستخدمًا بلا إعادة محاولة. مشتريات + مبيعات + سندات قبض مجتمعة حتى 150 طلبًا متزامنًا: 150/150 مرحَّلة، فرق 0، مخزون مطابق (بعد بوابة القبول). **مستندات المخزون (صرف داخلي + نقل) تحت 1–25 مستخدمًا: صحة تامة (82/82، فرق 0، مخزون مطابق) لكن زمن 27ث عند 25 مستخدمًا؛ الجرد والتسويات والعملات تحت الضغط لم تُقَس** |
| 10/25/50 مستخدمًا بصفر اختلاف | **PASS لمسار المبيعات** (182/182، فرق 0، تكرار 0) |
| Soak ≥ 60 دقيقة | **غير مُثبَت بعد**: ساعتان سابقتان باطلتان (انتهاء رمز الوصول بعد ≈560ث ثم 429 بملايين الطلبات)؛ صُحِّح الاختبار (تجديد الرمز + فشل إن لم يُرحَّل 95%) وأُعيد التشغيل. تشغيل قصير 240ث: 498 طلبًا كلها `201 Posted`، الذاكرة ثابتة ≈61MB |
| اختبارات SQL الصريحة الكاملة | غير مُشغَّلة كاملة (انظر `TEST_EXECUTION_EVIDENCE.md`) |
| التقارير (77/13/15) | غير مُعاد إثباتها |
| أمن الموديولات | توقيع حقيقي وإبطال: منفذ. **عزل العملية: غير منفذ** — لا تُركَّب موديولات خارجية غير موثوقة |
| Backup/Restore مجرَّب | **منفَّذ محليًا فقط**: 14 اختبار نسخ/استعادة ناجحة تشمل مطابقة الدفاتر بعد الاستعادة؛ لم يُجرَّب على خادم/جهاز آخر ولا ببيانات إنتاج |
