# 04 — قياسات خط الأساس (قبل/بعد)

**البيئة:** Windows 11 (10.0.26300) — جهاز تطوير واحد يشغّل الخادم والعملاء والاختبار وSQL Server Express محليًا (ليست LAN، ولا عتاد مرجعي). الجهاز كان مثقلاً بتطبيقات أخرى (CPU ≈ 60%)، فالأرقام المطلقة تقريبية والمقارنة قبل/بعد على الجهاز نفسه.
البيانات: بيانات اصطناعية من `PrepareNumberedSalesAsync` (فاتورة بسطرين، مخزون افتتاحي 5000 وحدة لتمرين مسار الترحيل الفعلي).
الأداة: `LedgerManagementHttpSqlTests.MeasureConcurrentSalesPostingAndLedgerIntegrity` (`--explicit on`). كل مستخدم يرسل طلبين `save-and-process` بوضع «اعتماد وترحيل».

**تحذير صريح عن الزمن:** الأزمنة المطلقة متذبذبة جدًا بين التشغيلات على هذا الجهاز المثقل (مثلاً 5 مستخدمين: 5.3ث ثم 15.2ث ثم 20.3ث) ولم أُجرِ مقارنة A/B مضبوطة لأثر البوابة على الزمن؛ لا أدّعي أن البوابة أسرع، بل أنها تمنع الفشل عند 150 طلبًا متزامنًا. مقارنة الزمن تحتاج بيئة معزولة.
